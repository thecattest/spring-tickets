       ```
       Бронь — {buyer_display_name}

       Сколько мест оплачено?
       ```

     - Send with `payment_quantity_keyboard(len(booked_seats))`

     - Wrap in try/except db.DatabaseError

     **Function `payment_quantity_handler(message, storage)`:**
     - Async function. Handles messages in PAYMENT_QUANTITY state.
     - Get text, context from storage
     - Extract: reservation_id, buyer_display_name, buyer_vk_user_id, buyer_vk_api_id, payment_vk_message_url, payment_vk_message_ts

     - **"Отмена" button:** Return to main menu. Use local import: `from bot.handlers.menu import show_main_menu`, then call `show_main_menu(message, storage, reservation_id, buyer_vk_user_id, buyer_display_name, buyer_vk_api_id)`. Return.

     - **Parse quantity:**
       - If text starts with "Все " (note the space): extract number after "Все ", parse as int. This is the "pay all" button.
       - Else: try `int(text)`. If ValueError: send "Выберите количество мест из предложенных кнопок." with current keyboard (need to re-query booked count). Return.
       - Store parsed number as `quantity`.

     - **Validate quantity:**
       - If quantity < 1: error message, return
       - Fetch current BOOKED seats: `seats = db.get_reservation_seats(reservation_id)` then filter BOOKED
       - If quantity > len(booked_seats): send error "Количество мест превышает доступные для оплаты ({len(booked_seats)}). Введите количество от 1 до {len(booked_seats)}:" with `payment_quantity_keyboard(len(booked_seats))`. Return.

     - **Record payment:**
       - `seller_id = db.get_default_seller_id()`
       - Parse vk_message_ts from context: if it's a string, convert with `datetime.fromisoformat()`. If None, leave as None.
       - Call `payment, paid_seats = db.record_payment(reservation_id, quantity, seller_id, vk_message_url=payment_vk_message_url, vk_message_ts=payment_vk_message_ts)`
       - Fetch updated seats to get remaining: `all_seats = db.get_reservation_seats(reservation_id)`, filter remaining BOOKED
       - Format confirmation: `format_payment_confirmation(paid_seats, remaining_booked, payment.payment_amount, buyer_display_name)`
       - Send confirmation message with `main_menu_keyboard()`

     - **Return to MAIN_MENU state:**
       - `await storage.set(message.from_id, BotState.MAIN_MENU, reservation_id=reservation_id, buyer_vk_user_id=buyer_vk_user_id, buyer_vk_api_id=buyer_vk_api_id, buyer_display_name=buyer_display_name, from_main_menu=True)`

     - **Error handling:**
       - Catch `db.InsufficientSeatsError as e`: send "Ошибка: запрошено {e.requested} мест, но доступно только {e.available}." with keyboard. Stay in PAYMENT_QUANTITY.
       - Catch `db.DatabaseError as e`: send "Ошибка при регистрации оплаты. Попробуйте позже." with main_menu_keyboard. Return to MAIN_MENU.

     - Register: `bot.on.message(state=BotState.PAYMENT_QUANTITY)(payment_quantity_with_storage)`
     - Log registration
