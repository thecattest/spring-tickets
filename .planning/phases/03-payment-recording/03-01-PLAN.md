  1. **bot/utils/db.py** — Add `InsufficientSeatsError` exception and `record_payment()` function:

     Add exception class after `SeatOccupiedError`:
     ```python
     class InsufficientSeatsError(DatabaseError):
         """Exception raised when requested payment count exceeds available BOOKED seats."""
         def __init__(self, requested: int, available: int):
             self.requested = requested
             self.available = available
             super().__init__(f"Requested {requested} seats but only {available} BOOKED seats available")
     ```

     Add import at top: `from models.payment import Payment, PaymentSeat`
     Add import: `from decimal import Decimal`

     Add function `record_payment()`:
     ```python
     def record_payment(
         reservation_id: int,
         seat_count: int,
         user_id: int,
         vk_message_url: Optional[str] = None,
         vk_message_ts: Optional[datetime] = None,
     ) -> tuple[Payment, List[SeatAssignment]]:
     ```

     Implementation (all inside `with SessionLocal() as session:` and try/except):
     a. Query BOOKED seats for this reservation: `SELECT * FROM seat_assignments WHERE reservation_id=X AND status='booked' AND released_at IS NULL ORDER BY row_number ASC, seat_number ASC`
     b. If len(booked_seats) < seat_count: raise InsufficientSeatsError(seat_count, len(booked_seats))
     c. Take first `seat_count` seats from the sorted list (deterministic selection)
     d. Calculate `payment_amount = Decimal(seat_count) * Decimal(SEAT_PRICE)` — import SEAT_PRICE from bot.config
     e. Create Payment record:
        ```python
        payment = Payment(
            reservation_id=reservation_id,
            recorded_by_user_id=user_id,
            vk_message_url=vk_message_url,
            vk_message_ts=vk_message_ts,
            payment_amount=payment_amount,
            seat_count=seat_count,
        )
        session.add(payment)
        session.flush()  # get payment.id before creating PaymentSeat
        ```
     f. For each selected seat: update `seat.status = SeatStatus.PAID` and create `PaymentSeat(payment_id=payment.id, seat_assignment_id=seat.id)`
     g. Update reservation.last_activity_at = datetime.utcnow()
     h. Create AuditLog with action_type="payment_recorded", entity_type="payment", entity_id=str(payment.id), payload including: reservation_id, seat_count, payment_amount (as float for JSON), seat_ids (list of seat assignment IDs), partial (bool: are there remaining BOOKED seats?)
     i. session.commit()
     j. Return (payment, selected_seats) — the list of SeatAssignment objects that were paid

     Error handling: catch InsufficientSeatsError and re-raise, catch IntegrityError (PaymentSeat unique constraint violation) and wrap in DatabaseError, catch general Exception and wrap in DatabaseError.
