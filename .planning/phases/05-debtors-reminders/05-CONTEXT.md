# Phase 5: Просмотр должников и напоминания - Context

**Gathered:** 2026-02-18
**Status:** Ready for planning

<domain>
## Phase Boundary

Билетеры видят список должников через /debtors, автоматические напоминания отправляются билетерам каждые 3 дня. Список только для просмотра — действия (отмена брони, оплата) выполняются через основной флоу бота. Клиентам напрямую бот не пишет.

</domain>

<decisions>
## Implementation Decisions

### Критерии должника
- Порог: 7 дней с последней активности (last_activity_at)
- Частичная оплата считается долгом — есть хотя бы 1 BOOKED место и прошло 7 дней = должник
- Нет верхнего предела давности — должник остаётся в списке пока есть неоплаченные BOOKED места
- Точка отсчёта: last_activity_at (сбрасывается при любом действии: добавление мест, частичная оплата)

### Логика напоминаний
- Получатель: билетер (не клиент) — билетер сам связывается с клиентом
- Частота: каждые 3 дня
- Время отправки: 20:00 МСК
- Формат: одно сообщение со списком всех должников билетера
- Если у билетера нет должников — сообщение не отправляется

### Отображение /debtors
- По каждому должнику: имя клиента, количество неоплаченных мест, сумма долга, сколько дней прошло
- Сортировка: по давности долга (самые старые сверху)
- Фильтрация: билетер видит только своих, админ — всех
- Пустой список по /debtors: показать «Должников нет»
- Только просмотр, без действий из списка (кнопка Обновить)

### Claude's Discretion
- Формат и стилистика текста сообщения-напоминания
- Реализация cron-скрипта (standalone Python или management command)
- Обработка ошибок VK API при отправке напоминаний
- Точный формат вывода /debtors (разметка, эмодзи)

</decisions>
