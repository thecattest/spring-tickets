Create scripts/ directory and scripts/send_debtors_reminders.py:

1. Script preamble:
   - Shebang line and docstring explaining the script purpose and crontab setup
   - Add crontab instructions in header comments:
     ```
     # Crontab entry (every 3 days at 20:00 Moscow time):
     # TZ=Europe/Moscow
     # 0 20 */3 * * /path/to/venv/bin/python /path/to/project/scripts/send_debtors_reminders.py >> /var/log/debtors_reminders.log 2>&1
     ```

2. Path setup:
   - `sys.path.insert(0, str(Path(__file__).parent.parent))` to make project root importable
   - `from dotenv import load_dotenv; load_dotenv()` to load .env

3. Imports (after path setup):
   - `from vkbottle.bot import Bot`
   - `from vkbottle import VKAPIError`
   - `from bot.config import VK_BOT_TOKEN`
   - `from bot.utils.db import get_debtors, get_all_active_sellers`
   - `from bot.messages import format_reminder`
   - `from database import init_db`

4. `async def main()`:
   - Call `init_db()` to ensure tables exist
   - Create Bot instance: `bot = Bot(token=VK_BOT_TOKEN)`
   - Call `get_all_active_sellers()` to get all AppUsers with vk_user_id IS NOT NULL
   - Initialize counters: sent_count=0, skipped_count=0, error_count=0
   - For each seller:
     - Call `get_debtors(seller_id=seller.id)` -- each seller gets ONLY their own debtors
     - If empty: increment skipped_count, continue
     - Format message: `format_reminder(debtors)`
     - Try sending via `await bot.api.messages.send(peer_id=seller.vk_user_id, message=message_text, random_id=0)`
     - On success: increment sent_count, log info
     - On VKAPIError: increment error_count, log error with seller ID and error details (do NOT re-raise -- other sellers must still be processed)
     - On generic Exception: increment error_count, log error (do NOT re-raise)
     - After successful send: call `log_reminder_sent(seller.id, debtor_count=len(debtors))` for audit trail
   - Log summary: f"Done. Sent: {sent_count}, Skipped: {skipped_count}, Errors: {error_count}"

5. Script entry point:
   - `if __name__ == "__main__":` block
   - Configure logging: `logging.basicConfig(level=logging.INFO, format='%(asctime)s %(levelname)s %(message)s')`
   - Run: `asyncio.run(main())`

Add to bot/utils/db.py:

6. `log_reminder_sent(seller_id: int, debtor_count: int)` function:
   - Creates AuditLog entry:
     - actor_type=ActorType.SYSTEM
     - actor_user_id=seller_id
     - action_type="debtors_notification_sent"
     - entity_type="reminder"
     - payload={"seller_id": seller_id, "debtor_count": debtor_count}
   - Follows existing audit logging pattern in db.py (SessionLocal with-block, commit)
