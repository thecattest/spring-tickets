  <action>
Add to bot/utils/db.py:

1. `get_debtors(seller_id=None)` function:
   - Computes threshold as `datetime.utcnow() - timedelta(days=7)` (NOT SQL INTERVAL -- SQLite does not support it)
   - Queries Reservation table: state == ReservationState.ACTIVE AND last_activity_at <= threshold
   - Uses a correlated subquery to count BOOKED seats per reservation: SeatAssignment where reservation_id matches, released_at IS NULL, status == SeatStatus.BOOKED. Filter: booked_count > 0 (must have at least one unreleased BOOKED seat to be a debtor)
   - JOINs VkUser on Reservation.buyer_vk_user_id == VkUser.id for buyer display name
   - If seller_id is not None, adds WHERE Reservation.sold_by_user_id == seller_id
   - Orders by Reservation.last_activity_at ASC (oldest first)
   - Returns list of dicts: `{'reservation_id': int, 'buyer_display_name': str, 'booked_seat_count': int, 'debt_amount': Decimal, 'days_since_activity': int, 'last_activity_at': datetime}`
   - Debt amount = booked_seat_count * Decimal(SEAT_PRICE)
   - days_since_activity = (datetime.utcnow() - last_activity_at).days
   - Follows existing SessionLocal() with-block pattern (see other functions in db.py)
   - Add `from datetime import timedelta` to imports (datetime already imported)
   - Add `from sqlalchemy import func` to imports if not already present

2. `get_all_active_sellers()` function:
   - Queries AppUser WHERE is_active == True AND vk_user_id IS NOT NULL
   - Returns list of AppUser objects
   - Uses existing SessionLocal pattern
   - This is used by the cron script (Plan 02) but defined here to keep all DB logic centralized

Add to bot/keyboards.py:

3. `debtors_keyboard()` function:
   - Returns inline keyboard with single button: "Обновить" (PRIMARY color)
   - Follow the exact same pattern as other keyboard functions (Keyboard with one_time=False, inline=True, returns .get_json())

Add to bot/messages.py:

4. `format_debtors_list(debtors: list) -> str` function:
   - Takes list of debtor dicts (from get_debtors)
   - Header line: "Должники ({count}):"
   - Empty line
   - For each debtor: buyer_display_name on one line, then indented details: "Мест: {count} | Долг: {amount} руб. | Дней: {days}"
   - Returns formatted multi-line string

5. `format_reminder(debtors: list) -> str` function:
   - Takes list of debtor dicts (from get_debtors)
   - Header line: "Напоминание о должниках ({count}):"
   - Empty line
   - For each debtor: compact format "{name} -- {seats} мест, {amount} руб., {days} дн. без активности"
   - Returns formatted multi-line string
   - This is used by the cron script for VK messages to sellers
