Use itertools.groupby pattern from research:
```python
from itertools import groupby
from operator import itemgetter

def format_seat_ranges(seats: list[int]) -> str:
    """
    Format consecutive seats as ranges.

    Args:
        seats: Sorted list of seat numbers

    Returns:
        Formatted string like "1-3, 5, 7-9"

    Examples:
        [1, 2, 3, 5, 7, 8, 9] -> "1-3, 5, 7-9"
        [5] -> "5"
        [] -> ""
    """
```

The groupby trick: `enumerate(seats)` pairs each seat with its index. For consecutive seats, `index - seat_number` remains constant, so they group together.

Handle edge cases:
- Empty list -> return ""
- Single element -> return just that number
- All consecutive -> return "first-last"
- No consecutive -> return comma-separated

Add `__all__` export list.
