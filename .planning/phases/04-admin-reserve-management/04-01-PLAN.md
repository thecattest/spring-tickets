Add three new functions to `bot/utils/db.py`. Follow the exact pattern of existing functions (SessionLocal context manager, try/except/rollback, audit logging, logger.info).

1. `get_app_user_by_vk_id(vk_user_id: int) -> Optional[AppUser]`
   - Query AppUser where `vk_user_id == vk_user_id` and `is_active == True`
   - Return AppUser or None
   - Raise DatabaseError on failure
   - Needed to get `created_by_user_id` for SeatAssignment (must be AppUser.id, NOT VK user ID)

2. `add_reserve(row: int, seats: List[int], comment: str, user_id: int) -> List[SeatAssignment]`
   - Atomic: check all seats available first (same pattern as `add_seats_to_reservation`)
   - For each seat: create SeatAssignment with:
     - `status=SeatStatus.RESERVED`
     - `reservation_id=None` (reserves are NOT tied to reservations)
     - `created_by_user_id=user_id`
     - `note=comment`
   - Commit all at once
   - Audit log entry: action_type="reserve_added", entity_type="seat_assignment", payload includes row, seats, comment, user_id
   - If any seat is occupied, raise SeatOccupiedError (same as add_seats_to_reservation)
   - Raise DatabaseError on other failures

3. `release_reserve(row: int, seats: List[int], user_id: int) -> List[dict]`
   - Query SeatAssignment WHERE row_number=row AND seat_number IN seats AND status=RESERVED AND released_at IS NULL
   - If not all seats found: raise DatabaseError with details about which seats are not reserved
   - For each found assignment: set `released_at = datetime.utcnow()`, set `released_by_user_id = user_id`
   - Collect previous notes: `[{"seat": s.seat_number, "note": s.note} for s in assignments]`
   - Audit log: action_type="reserve_removed", entity_type="seat_assignment", payload includes row, seats, previous_notes, user_id
   - Commit and return the list of dicts with previous notes

IMPORTANT: Do NOT use `get_default_seller_id()` for reserves. Use the actual admin's AppUser.id (passed as `user_id` parameter).
