**1. RowResult dataclass and handle_row_input()**
```
@dataclass
class RowResult:
    ok: bool
    row: Optional[int] = None
    error_text: Optional[str] = None
```

`handle_row_input(text: str) -> RowResult`:
- Strip input, try `int(text)`
- On ValueError: return `RowResult(ok=False, error_text=texts.ERR_INVALID_ROW_FORMAT.format(min_row=..., max_row=...))`
- On invalid row (not `is_valid_row(row)`): return `RowResult(ok=False, error_text=texts.ERR_INVALID_ROW.format(min_row=..., max_row=...))`
- On success: return `RowResult(ok=True, row=row)`
- Uses lazy imports inside function body: `from bot.utils.layout import is_valid_row, get_row_range` and `from bot import texts`

**2. SeatResult dataclass and handle_seat_input()**
```
@dataclass
class SeatResult:
    ok: bool
    seats: Optional[list[int]] = None
    error_text: Optional[str] = None
```

`handle_seat_input(text: str, row: int, mode: Literal["layout_only", "availability", "membership"], reservation_id: Optional[int] = None) -> SeatResult`:

Three validation phases:
- **Parse:** Call `parse_seats(text.strip())`. On `SeatParseError`: return error with `texts.ERR_PARSE_INPUT.format(error=str(e))`
- **Layout check (all modes):** Check `is_valid_seat(row, s)` for each seat. If invalid seats found: return error with `texts.ERR_INVALID_SEATS.format(seats=..., row=..., seat_count=...)`
- **Mode-specific check:**
  - `"layout_only"`: return `SeatResult(ok=True, seats=seats)` immediately
  - `"availability"`: For each seat, call `db.get_seat_assignment(row, seat)`. Collect occupied seats. If any occupied, build detailed error message showing status (Резерв/Бронь/Оплачено) and details. Use `from models.base import SeatStatus` for status comparison. Format: "Места уже заняты:" followed by bullet lines, ending with "Введите другие места:". Follow the exact format from the research code example.
  - `"membership"`: Call `db.get_reservation_seats(reservation_id)` to get all seats. Build `seat_map = {(s.row_number, s.seat_number): s for s in all_seats}`. Check seats not in reservation -> error with `texts.MSG_SEATS_NOT_IN_BOOKING`. Check PAID seats -> error with `texts.MSG_SEATS_ALREADY_PAID`. Use `from models.base import SeatStatus` for PAID check.

Uses lazy imports inside function body to avoid circular imports.

**3. handle_confirmation()**

`handle_confirmation(text: str) -> Optional[bool]`:
- Strip input
- Compare to `Btn.CONFIRM` -> return `True`
- Compare to `Btn.CANCEL` -> return `False`
- Otherwise -> return `None`
- Uses lazy import: `from bot.constants import Btn`

**Module docstring:** Explain that these are pure input validation primitives. They return typed results. Handlers call message.answer() based on results. Steps never call message.answer() or storage.set().

**Logging:** Add `logger = logging.getLogger(__name__)` at module level. No logging inside the functions (they're pure).

**CRITICAL constraints:**
- No `message: Message` parameter anywhere — these are pure functions
- No `storage` parameter anywhere — state transitions are the handler's job
- No `await` anywhere — these are synchronous functions
- All user-facing strings come from `bot.texts` or are built inline for availability mode (the detailed occupied-seats message)
- All button comparisons use `Btn.*` constants, not raw strings
