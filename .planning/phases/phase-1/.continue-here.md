<fix_summary>

**Redis FSM Storage Fix**

**Problem:**
- Custom ABCStateDispenser implementation was returning strings
- vkbottle expects StatePeer objects with `.state` attribute
- State rule matching (`state=BotState.AWAITING_ROW`) was failing

**Root Cause:**
- vkbottle's internal state system uses Pydantic StatePeer models
- get() must return StatePeer instances, not plain strings
- StatePeer contains: peer_id, state, payload (context data)

**Solution:**
1. Rewrote RedisStorage.get() to return StatePeer objects
2. Store full StatePeer data in Redis (JSON serialization)
3. Use StatePeer.payload for context (reservation_id, current_row, etc.)
4. Updated handlers to pass context via **kwargs to set()

**Testing:**
- Created test_redis_fsm.py with 8 comprehensive tests
- All tests pass: storage, retrieval, context preservation, deletion
- Verified StatePeer has .state attribute as required by vkbottle

**Files Changed:**
- bot/fsm/storage.py: Complete rewrite (70 lines removed, simpler)
- bot/main.py: Switched from BuiltinStateDispenser to RedisStorage
- bot/handlers/reservation.py: Updated to new storage API
- bot/tests/test_redis_fsm.py: New integration tests

</fix_summary>
