Create `bot/router.py` with the following structure:

**Class: Router**
- `__init__(self, storage: RedisStorage)` — stores `self.labeler = BotLabeler()` and `self.storage = storage`
- `register_all(self)` — calls `_register_forwarded()`, `_register_commands()`, `_register_states()` in that exact order, then logs handler count via `len(self.labeler.message_view.handlers)`
- `_wrap(self, handler_func)` — returns an async closure `wrapped(message: Message)` that calls `await handler_func(message, storage)`. Set `wrapped.__name__ = handler_func.__name__ + "_wrapped"` for debug traceability.

**Method: _register_forwarded()**
Lazy import `forwarded_message_handler` from `bot.handlers.reservation`.
Register with `self.labeler.message(func=lambda msg: bool(msg.fwd_messages))`.
Wrap with `self._wrap()` (handler takes storage).

**Method: _register_commands()**
Lazy imports from:
- `bot.handlers.commands`: `start_handler`, `help_handler`, `cancel_handler`
- `bot.handlers.reserve`: `reserve_command_handler`
- `bot.handlers.debtors`: `debtors_command_handler`, `refresh_debtors_handler`

Registrations (order matters for dispatch priority):
1. `text="/start"` -> `start_handler` (no wrap — takes only message)
2. `text=["/help", "/Справка"]` -> `help_handler` (no wrap)
3. `text=["/cancel", "/Отмена"]` -> `self._wrap(cancel_handler)` (needs storage)
4. `text=["/reserve", "/Резерв"]` -> `self._wrap(reserve_command_handler)` (needs storage)
5. `text=["/debtors", "/Должники"]` -> `debtors_command_handler` (no wrap)
6. `text="Обновить"` -> `refresh_debtors_handler` (no wrap — stateless)

IMPORTANT: `start_handler` and `help_handler` do NOT take storage — register them directly without `_wrap()`. Check each handler's signature: if it takes `(message, storage)` -> wrap; if only `(message)` -> register directly.

**Method: _register_states()**

All state handlers take `(message, storage)` — wrap all with `self._wrap()`.
Register each with `self.labeler.message(state=state)(self._wrap(handler_func))`.

**Anti-patterns to avoid (and why):**
- NO module-level handler imports — causes circular imports because handler files import from bot.fsm which may transitively reference router
- NO `bot.on.message()` — Router uses `self.labeler.message()` (its own labeler, not the bot's)
- NO auth guard enforcement at router level — auth is already handled inside each handler function; adding it here would add a DB query to every message
- Use `from vkbottle.framework.labeler.bot import BotLabeler` (NOT `from vkbottle import BotLabeler`)

Add module docstring explaining the three registration groups and why order matters (vkbottle dispatches to first matching blocking handler).
