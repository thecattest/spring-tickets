# Система продажи билетов через VK бота

## What This Is

Система управления продажей билетов на концерт для команды билетеров через VK бота. Билетеры пересылают боту сообщения клиентов для создания броней, управляют местами (добавление/удаление), регистрируют оплату и получают готовые скрипты для отправки клиентам. Админы дополнительно управляют резервами с комментариями и видят общую статистику. Архитектура бота построена на центральном роутере с декларативным FSM-конфигом, переиспользуемыми шагами и единым источником правды для UI-строк.

## Core Value

**Ни одно место не может быть продано дважды.** Все операции с местами атомарны, уникальность занятости гарантируется partial index на уровне БД, конфликты выявляются до коммита транзакции.

## Context

**Текущее состояние (после v0.2):**
- 5,997 строк Python в bot/
- 18 FSM состояний в декларативном FSM_CONFIG
- Центральный роутер (bot/router.py) с автоматической инъекцией storage и auth guard
- 3 переиспользуемых шага (bot/steps.py) заменяют ~335 строк дублирования
- 62+ констант сообщений в bot/texts.py, все кнопки через Btn StrEnum
- /cancel → back-step navigation, /exit → hard reset to IDLE
- Ранняя валидация ряда в 4 хендлерах
- Pre-existing pytest failures (12) — не связаны с v0.2, существовали до рефакторинга

## Constraints

- **Технический стек**: Python 3.14+, vkbottle, Redis, SQLAlchemy 2.0+, SQLite
- **Макет зала**: layout.json не меняется
- **Обратная совместимость**: Все существующие потоки работают идентично

## Key Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| vkbottle вместо aiogram | aiogram только для Telegram, vkbottle специально для VK с встроенной FSM | ✓ Good |
| Redis для FSM состояния | Permanent storage без TTL, очистка только явная | ✓ Good |
| Детерминированная частичная оплата | Простота реализации, предсказуемость (row ASC, seat ASC) | ✓ Good |
| SeatAssignment.note только для резервов | Комментарии нужны только админам | ✓ Good |
| Один клиент = одна бронь | Упрощает логику, предотвращает путаницу | ✓ Good |
| /cancel → назад на шаг, /exit → IDLE | Более естественная навигация для билетеров | ✓ Good — v0.2 |
| Router с middleware вместо ручных dispatch блоков | Единая точка входа для всех команд, нет дублирования | ✓ Good — v0.2 |
| StrEnum для кнопок | Единый источник правды для UI-строк, защита от опечаток | ✓ Good — v0.2 |
| FSM_CONFIG keyed by BotState enum | Type-safe access, handler=None до Phase 10 Router | ✓ Good — v0.2 |
| Lazy imports inside handler functions | Предотвращает circular imports при модульной архитектуре | ✓ Good — v0.2 |
| from_main_menu flag для AWAITING_ROW | Разрешает неоднозначность back-navigation (MAIN_MENU vs IDLE) | ✓ Good — v0.2 |
