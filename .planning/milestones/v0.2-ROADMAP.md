## Milestone Summary

**Key Decisions:**

- StrEnum members ARE strings — Btn.ADD == "Добавить" is True, no .value needed
- FSM_CONFIG keyed by BotState enum member (not string) — type-safe access
- Router uses self.labeler (BotLabeler) NOT bot.on — wired via bot.labeler.load(router.labeler)
- All bot.handlers.* imports lazy (inside function bodies) — prevents circular imports
- /cancel → back one step via FSM_CONFIG.back_state, /exit → hard reset to IDLE
- AWAITING_ROW ambiguity resolved via from_main_menu flag in payload

**Issues Resolved:**

- Context switch "Нет" button bug — BotState(stored_string.split(':')[-1]) handles both formats
- Commands only working from 2 states — universal command interceptor in router
- ~335+ lines of duplicated validation code — replaced by 3 shared step functions

**Issues Deferred:**

- Phase 6 (Статистика) — deferred to v0.3
- Pre-existing pytest failures (12 total) — not caused by v0.2, existed before refactoring

**Technical Debt Incurred:**

- None significant — clean refactoring with zero regressions
